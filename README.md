# CS231n — Deep Learning for Computer Vision

Stanford CS231n 课程作业实现。**版本：Spring 2026**


## Assignment 1
- `knn.ipynb` — k 最近邻分类器
- `softmax.ipynb` — Softmax 线性分类器
- `two_layer_net.ipynb` — 两层全连接神经网络
- `FullyConnectedNets.ipynb` — 模块化多层全连接网络与优化器（SGD + Momentum / RMSProp / Adam）
- `features.ipynb` — 基于图像特征（HOG / 颜色直方图）的分类

## Assignment 2
- `ConvolutionalNetworks.ipynb` — 卷积层与池化层的前向 / 反向传播
- `BatchNormalization.ipynb` — Batch Normalization 与 Layer Normalization
- `Dropout.ipynb` — Dropout 正则化
- `PyTorch.ipynb` — 用 PyTorch 实现并训练 CIFAR-10 分类网络
- `RNN_Captioning_pytorch.ipynb` — 基于 RNN 的图像描述生成

## Assignment 3
- `Transformer_Captioning.ipynb` — 基于 Transformer 的图像描述生成
- `Self_Supervised_Learning.ipynb` — 自监督表示学习
- `DDPM.ipynb` — 去噪扩散概率模型
- `CLIP_DINO.ipynb` — CLIP 与 DINO 的表示与注意力分析
